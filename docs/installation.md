# Installation

## Stable release

To install care_im_wrapper, run this command in your terminal:

```sh
pip install care_im_wrapper
```

## From source

The source files for care_im_wrapper can be downloaded from the [Github repo](https://github.com/8sami/care_im_wrapper).

You can either clone the public repository:

```sh
git clone git://github.com/8sami/care_im_wrapper
```

Or download the [tarball](https://github.com/8sami/care_im_wrapper/tarball/master):

```sh
curl -OJL https://github.com/8sami/care_im_wrapper/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd care_im_wrapper
pip install .
```
